# MIS-final-project
Customer-facing frontend pages for an MIS academic project. Developed using HTML, CSS, and vanilla JavaScript as a static web interface prototype.

## Overview
This project contains the customer-facing interface of the MIS system, developed as part of a university coursework project. The website is built entirely with HTML, CSS, and JavaScript without backend or database integration.

## Features
- Static customer pages
- Navigation and UI interactions
- Clean frontend structure

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Note
This repository focuses only on frontend/UI implementation and does not include server-side functionality or dynamic database operations.
